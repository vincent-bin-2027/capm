# CAPM experiment

A small personal notebook where I try out CAPM regressions on a handful of S&P 500
stocks. It uses daily data from Yahoo Finance, the 3-month Treasury bill rate as
the risk-free rate, and rolling 252-day regressions to see how the beta changes
over time.

## Files

- `capm.ipynb` — the notebook.
- `returns.csv`, `sp500_returns.csv`, `TB3MS.csv` — cached data used by the notebook.
